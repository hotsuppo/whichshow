「どっちでSHOW」4作品統合版

ZIPを新しいフォルダに解凍し、その中の index.html を開いてください。
4つのカードを押すとそれぞれのゲームが始まります。各ゲームのトップ画面と結果画面にある「問題選択に戻る」で選択画面へ戻れます。
選択画面の画像「どっちでSHOW_タイトル画面.png」も同じフォルダに置いてください。ZIPをそのまま解凍すれば自動で揃います。
問題数：セか？パか？229問／昭和か？平成か？415問／Nか？Rか？146問／関西か？関東か？534問。

GitHubにはZIPを解凍した11ファイルすべてをリポジトリ直下に配置してください。kansai_data_1.js、kansai_data_2.js、kansai_data_3.jsは関西・関東クイズに必要です。
